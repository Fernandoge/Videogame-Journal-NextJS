# Learning Roadmap — Videogame Journal

This project is your textbook. Every concept below is explained using code that
already exists in this codebase — no toy examples, no abstract demos.

Read the docs in order the first time. After that, use them as a reference you
can jump into at any point.

## How to use these docs

Each doc follows the same structure:
1. **What it is** — plain English explanation of the concept
2. **In this project** — exactly where to find it in the codebase
3. **Key things to notice** — the specific patterns worth understanding
4. **Try this** — a small experiment you can do to deepen understanding

The best way to learn is to read a concept, find the referenced file, read that
code, then do the experiment. Changing real code and seeing what breaks (or works)
is worth ten times more than reading alone.

---

## Prerequisites

You don't need to know any of this before starting. Each doc assumes only that
you've read the ones before it.

If you're completely new to programming concepts, you might want to spend 30
minutes with the basics of JavaScript (variables, functions, arrays, objects)
before starting — but even that isn't strictly required.
